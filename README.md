# drifting-models-pytorch

PyTorch implementation scaffold for generative modeling via drifting models.

This repository is intentionally initialized without algorithm implementation yet.

## Setup

```bash
uv sync --group dev
uv run pre-commit install
```

## Commands

```bash
uv run invoke --list
uv run invoke format
uv run invoke lint
uv run invoke typecheck
uv run invoke test
```

For one-command commit with autofixes:

```bash
uv run invoke commit -m "Initial scaffold"
```

## Structure

- `drifting_models_pytorch/`: package source (placeholder only)
- `examples/`: runnable examples (placeholder only)
- `tests/`: test suite
- `paper/`: copied paper assets
